# Phase II V2 Physical Repair and Best-of-N Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Execute inline with a fresh verification gate after each task.

**Goal:** Rebuild a physically image-disjoint downstream V2 manifest and execute the user-frozen Best-of-N protocol without changing any Phase I or static artifact.

**Architecture:** Keep the static anchor and invalid original downstream manifest immutable. Reconstruct the original GQA and TallyQA eligibility pools from the repository-named public source archives, deterministically replace only physical-image conflicts, then execute one N=8 pairwise graph per pool and derive N=2/N=4 induced-subgraph outcomes.

**Tech Stack:** Existing Python 3.12 venv, stdlib hashlib/json/unittest, validated model-native adapters.

**Spec:** User scientific authorization, 2026-09-13.
